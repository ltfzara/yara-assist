# Yara Assist — Finance Phase 1

این بسته روی نسخه `yara-supabase-auth-shops-v2.zip` ساخته شده و قابلیت‌های فعلی احراز هویت، فروشگاه‌ها، سفارش‌ها و مشتریان را حفظ می‌کند.

## پیش از اجرا
1. از Supabase و فایل‌های فعلی پروژه نسخه پشتیبان بگیرید.
2. ابتدا migration فعلی پروژه را اجراشده فرض کنید؛ این migration جدید مکمل آن است و جایگزین آن نیست.
3. فایل `supabase/yara-finance-phase1-migration.sql` را در SQL Editor اجرا کنید.
4. سپس `index.html` را در مخزن GitHub جایگزین کنید و اجازه دهید Vercel منتشر کند.

## موارد اضافه‌شده
- تنظیم واحد پول مستقل برای هر فروشگاه (تومان، دلار، یورو، لیر، درهم).
- کاتالوگ محصولات با مدل تأمین خریدنی/تولیدی/ترکیبی.
- هزینه استاندارد هر واحد: خرید، تولید، بسته‌بندی و زمان ساخت × دستمزد ساعتی.
- ثبت و حذف هزینه‌های عملیاتی فروشگاه.
- صفحه نمای کلی مالی با درآمد سفارش‌های واجد شرایط، هزینه‌های ثبت‌شده و توضیح شفاف درباره نامشخص بودن سود.
- جداول `order_items` برای snapshot هزینه در سطح اقلام سفارش و ستون‌های مستقل ارسال پرداختی فروشنده، مبلغ ارسال دریافتی از مشتری و کمیسیون.
- RLS فروشگاه‌محور برای جداول جدید.

## محافظت از داده‌های قدیمی
- هیچ سفارش قدیمی تغییر داده یا حذف نمی‌شود.
- سفارش‌های قدیمی با وضعیت بهای تمام‌شده `unknown` باقی می‌مانند.
- هیچ هزینه فعلی به‌صورت ساختگی به سفارش قدیمی نسبت داده نمی‌شود.
- محصول حذف فیزیکی نمی‌شود؛ غیرفعال می‌شود تا ارتباط تاریخی قابل حفظ باشد.

## محدوده این مرحله و موارد باقی‌مانده
این مرحله زیرساخت مالی، تنظیمات پول، کاتالوگ محصولات و ثبت هزینه‌های عملیاتی را فراهم می‌کند. فرم سفارش فعلی هنوز به انتخاب محصول از کاتالوگ و ایجاد خودکار `order_items` متصل نشده است؛ بنابراین سود سفارش/سود خالص عمداً نمایش داده نمی‌شود. این اتصال باید در مرحله بعد، همراه با پشتیبانی از چند قلم در هر سفارش و snapshotهای هزینه، انجام شود.

همچنین مشتریان فعلاً مانند نسخه قبلی از سفارش‌ها استخراج می‌شوند؛ جدول مستقل مشتریان و ادغام امن سوابق در مرحله بعد اضافه می‌شود.

## نکته مهم درباره ارز
تنظیم واحد پول فروشگاه برای داده‌های مالی جدید اعمال می‌شود. اعداد سفارش‌های قدیمی بدون تبدیل ارزی حفظ می‌شوند؛ اگر آن‌ها با واحد پول متفاوتی ثبت شده‌اند، نباید گزارش‌های تاریخی را با ارز جدید مقایسه کرد.
